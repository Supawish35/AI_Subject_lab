Methodology & Mathematical Formulation

1. Euclidean Distance Metric
d(p, q) = √( Σ (pᵢ - qᵢ)² )
วัดระยะห่างเชิงเรขาคณิตระหว่างเวกเตอร์ตัวอย่างทดสอบกับตัวอย่างทั้งหมดในชุดฝึกสอน (Training Set)
2. Feature Normalization (Min-Max)
x_norm = (x - min) / (max - min)
ปรับสเกลข้อมูลทุก Feature ให้อยู่ในช่วง [0.0, 1.0] เพื่อไม่ให้คอลัมน์ที่มีค่าสูงครอบงำการคำนวณระยะห่าง
3. Majority Voting Decision
ŷ = argmax_c Σ I(yᵢ = c)
นับคะแนนเสียงจาก K เพื่อนบ้านที่ใกล้ที่สุด คลาสที่ได้รับคะแนนโหวตสูงสุดจะถูกกำหนดเป็นผลลัพธ์การทำนาย
